# 项目 Spec：hangar（原 codex-switcher）

> Codex 多账号切换 CLI/TUI/GUI 工具。本文档是需求与验收的唯一权威入口。
>
> 当前状态：v0.6.0 已发布，v0.7.0 CLI/TUI 候选已验收；GUI 保留既有能力并进入维护模式。

## 目标

让使用 OpenAI Codex 的用户在多个 ChatGPT 账号间**免重复登录**地切换：

1. 切换账号 = 一条命令/一次按键，秒级生效
2. 账号凭据长期保活：官方 Codex 轮换 refresh_token 后自动收敛，不失效
3. 官方 `auth.json` 是唯一权威（Authority），本工具只是缓存与投影

## 用户场景

| 场景 | 用户动作 | 期望结果 |
|------|----------|----------|
| 多账号切换 | 选中账号回车 | 官方 auth.json 被投影为目标账号，Codex 重启后生效 |
| 添加账号 | 完成一次 OAuth 登录 | 账号仅入库，不改变当前激活账号或官方 auth.json；由用户显式切换 |
| 长会话后切回 | Codex 运行数小时后切回该账号 | harvest 自动回收官方轮换的新 RT，切换成功不要求重登 |
| 账号在 Codex 侧重新登录 | 用户手动 `codex login` | 下次打开工具自动收编为新账号（S5） |
| RT 失效 | 服务端撤销/轮换链断裂 | 账号标 stale，拒绝投影污染官方登录态，定向复活 |
| 配额速览 | 打开配额面板 | 每账号显示窗口剩余 % 与重置时间、重置卡数量 |
| 使用建议 | 查看全账号周剩余 | 在不自动切换的前提下，按周剩余和稳定阈值标记建议账号 |
| 异常排查 | 自检 | 离线输出凭据完整性/权限/一致性问题清单 |

## 范围

**做：**

- OAuth（chatgpt 模式）账号的登录、切换、复活、删除
- 官方 auth.json 的 harvest（官方→库收敛）与投影（库→官方 merge 写）
- macOS keychain 快照同步、config.toml 自定义 provider 清理
- 配额查询（wham/usage，非公开契约）与重置卡只读展示
- 三前端：全屏 TUI（默认）、经典菜单（管道/--classic 回退）与 egui GUI
- 可脚本化一次性 CLI：账号列表/当前账号/切换/登录/复活/删除/配额/自检/收敛/更新，支持脱敏 JSON 输出与稳定失败退出码
- GUI 系统托盘：账号快捷切换、显示主窗口与退出；Linux 使用 SNI，macOS/Windows 使用原生托盘
- macOS 关闭主窗口后进入菜单栏驻留态并从 Dock 隐藏；从托盘显示时恢复 Dock 与窗口
- CLI/Core 与 GUI 按变更范围独立运行三平台 CI；CLI 与 GUI 使用独立发布标签，Windows 仅保留源码兼容门禁

**不做（非目标）：**

- API-Key 模式账号管理
- 核销重置卡（consume 属破坏性操作）
- 配额历史的持久化与图表
- Windows/Linux 系统钥匙串加密存储（明文 + 权限收紧是当前安全模型）
- 管理官方 config.toml 的其他配置项
- CLI/TUI 新版本不默认捆绑 GUI 功能或 GUI 版本发布；classic/GUI 不得绕过 core 复制业务规则

## 关键约束

- 凭据为明文存储：目录 `700`、文件 `600`；错误日志只记 `status+error_code+body_len`
- `refresh_token` 轮换敏感：任何"先写官方后写库"的顺序都可能造成 RT 丢失（S11 先库后官方）
- `redirect_uri` 必须严格匹配官方 Hydra 白名单：`localhost:{1455,1457}/auth/callback`

## 验收标准

1. **免重复登录**：官方轮换 RT 后（真实场景或模拟），工具切换任一账号无需浏览器重登
2. **收敛安全**：harvest 不接受过期 id_token；空 AT 账号拒绝投影并标 stale
3. **守卫完备**：切换/删除"使用中"账号被拦截且不产生任何写官方文件的副作用
4. **登录成功率**：标准 OAuth 流程在 1455 或 1457 至少一个端口可用时一次通过
5. **崩溃恢复**：accounts.json 损坏时从 .bak 自动恢复；原子写不留半截文件
6. **回归验证**：`cargo test` 全绿，TUI/classic/GUI 三前端按变更范围完成冒烟
7. **添加安全**：新增账号不自动切换，不改变 `current_account_id` 与官方 auth.json
8. **托盘一致性**：托盘 current/stale/busy 守卫与 GUI 主窗口一致，切换成功后勾选项同步
9. **macOS 生命周期**：关闭主窗口后 Dock 图标消失但进程驻留；托盘可恢复窗口；退出动作真正结束进程
10. **脚本化契约**：一次性命令未知参数必须失败；账号选择歧义不得猜测；JSON 不包含 token；正常数据只写 stdout、诊断写 stderr
11. **非交互安全**：删除必须显式确认参数；一次性命令不在执行前隐式自升级；任何守卫失败不得改写官方 auth.json
12. **CLI/TUI 对等**：v0.5 新增核心动作在一次性 CLI 与 TUI 均可达；GUI 只要求共享 core 回归不破坏既有能力
13. **刷新安全**：JWT `exp` 优先于本地账本；过期/临期 AT 无法刷新时拒绝切换且不改写官方 auth.json
14. **TUI 总览**：首屏可同时比较全部账号的当前状态、令牌健康与已加载主要配额；未知值不得显示为 0%
15. **周额度建议**：启动后顺序加载全部正常账号的周剩余；推荐排除 stale/未知账号，当前账号与最高值相差不超过 10 点时保持推荐当前账号，且推荐不得产生写入或自动切换
