# hangar v0.7.0

> 状态：候选已验收，待 `v0.7.0` CLI 标签发布。

## 主要变化

- TUI 启动后在单后台任务中顺序查询全部正常账号，周剩余逐行回填，浏览和退出不被阻塞。
- 总览和详情统一只展示当前生效的“周剩余”；core 仍容错保留服务端返回的其他窗口，JSON 契约不变。
- 新增可解释的账号建议：排除 stale/未知账号，优先周剩余最高者；当前账号与最高值相差不超过 10 个百分点时建议继续使用当前账号。
- 推荐只影响展示，不自动切换、不联网、不写文件；classic 具有对等的周剩余和建议输出。

## 刷新安全与兼容性

- `Account`/`AccountsFile` 持久化结构不变，v0.6.0 账号库无需迁移。
- 不新增守护进程或定时 refresh token 刷新；仍只在配额查询、切换等需要有效 AT 的操作中按需刷新。
- 刷新后仍严格保持 S11：先写账号库，后投影官方 `auth.json`；查询非当前账号不覆盖官方登录态。
- CLI 与 GUI 使用独立发布通道。本轮只发布 CLI 0.7.0，GUI/Tauri 继续保持 0.6.0。
