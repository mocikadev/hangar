# hangar v0.6.0

> 状态：本地发布候选；尚未创建 tag 或 GitHub Release。

## 主要变化

- TUI 首屏升级为多账号总览，可同时比较当前状态、计划、主要配额窗口以及 AT/RT 健康状态。
- 支持按邮箱过滤、折叠或展开日志，并在全部配额后台查询期间继续浏览账号。
- `list --json` 与 `current --json` 增加 `schema_version` 和脱敏后的 token health，继续保证不输出任何凭据。
- `doctor`、CLI 与 TUI 统一使用 JWT `exp` 优先、账本有效期回退的令牌健康规则。
- 刷新失败改为结构化错误分类；AT 已过期或临期且无法刷新时拒绝投影，防止覆盖仍然有效的官方登录态。
- 显式 `harvest` 失败会返回失败结果；启动期收敛仍保持 best-effort。

## 安全与兼容性

- `Account`/`AccountsFile` 持久化结构不变，v0.5.0 账号库无需迁移。
- OAuth client、redirect URI、回调端口和授权范围不变。
- S11 继续保持“先保存账号库、后投影官方 `auth.json`”。
- 不新增守护进程或定时刷新；只在切换、配额查询等需要有效 AT 的操作中按需刷新。
- GUI 不新增功能，但 crate 与安装包版本同步到 0.6.0，并继续参与三平台源码 CI。
