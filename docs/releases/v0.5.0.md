# hangar v0.5.0

> 状态：候选审计与 Linux/macOS/Windows CI 全绿，待创建 release tag；尚未发布。

## 主要变化

- 新增可脚本化的一次性 CLI：`list`、`current`、`switch`、`login`、`reauth`、`remove`、`quota`、`doctor`、`harvest`、`update`。
- 新增脱敏 `--json` 输出与稳定退出码；未知参数、账号歧义和状态守卫不再静默通过。
- selector 支持完整账号 ID 或唯一邮箱；删除必须显式传入 `--yes`。
- 一次性命令不在执行前隐式升级，正常数据写 stdout，诊断写 stderr。
- TUI 启动时只刷新当前账号配额；“刷新当前配额”和“刷新全部配额”分离，后台查询期间仍可浏览、过滤和查看。

## 安全与兼容性

- `Account`/`AccountsFile` 格式没有变化，现有账号库无需迁移。
- S11 保持“先写账号库、后写官方 auth.json”，OAuth 回调白名单保持不变。
- JSON 由显式安全 DTO 构造，不包含 access token、refresh token 或 id token。
- GUI 不新增 v0.5 功能，继续维护 v0.4 已有账号、配额和托盘能力；包版本同步为 0.5.0。

## 发布资产范围

- CLI：Linux amd64/arm64、macOS amd64/arm64。
- GUI：Linux amd64 `.deb`/`.rpm`/`.AppImage`、Linux arm64 `.deb`、macOS amd64/arm64 `.dmg`。
- 校验：`SHA256SUMS.txt` 覆盖全部上传资产。
- Windows：本轮不发布二进制或安装包；仅保留 CI 编译与测试门禁。

## 已知限制

- macOS 应用使用 ad-hoc 签名，没有 Developer ID 签名或 Apple 公证；首次打开可能需要在“隐私与安全性”中确认。
- 配额接口属于非公开接口，字段缺失时显示“未知”。
- GUI 处于维护模式，一次性命令和 JSON 自动化能力仅由 CLI/TUI 提供。

## 升级与回滚

- CLI 可通过自动更新、`hangar update` 或安装脚本升级。
- GUI 需要从 GitHub Releases 下载对应安装包覆盖安装。
- 如需回滚，可重新安装 v0.4.0 Release；账号库格式保持兼容。
