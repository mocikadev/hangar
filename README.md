# hangar

> **Codex 多账号管理工具**：免重复登录，秒级切换，TUI 仪表盘。

一个本地 CLI/TUI 工具（bin 名 `hangar`），解决 Codex 用户的真实痛点——**多账号之间切换要重新走一遍浏览器登录**。本工具把每个账号的凭据安全地缓存在本地，切换时直接投影到官方 `auth.json`，官方 Codex 轮换令牌后还能自动收敛回来，账号永不失效。

## 解决什么问题

| 痛点 | hangar 的方案 |
|------|----------------------|
| 切换账号要重新浏览器登录 | 凭据本地缓存，切换零登录，秒级生效 |
| Codex 运行中会轮换 refresh_token，第三方工具存的旧令牌会失效 | 每次交互前 **harvest 收敛**：官方文件是唯一权威，轮换后自动回收 |
| 在 Codex 里手动登录了新账号，其他工具不认识 | **反向收编**：发现未知账号自动入库（S5） |
| 令牌失效后切换会污染正常登录态 | stale 标记 + 守卫：失效账号拒绝投影；使用中账号禁止切换/删除 |
| 切换后 Codex 还在跑，不知道是否生效 | 自动检测 Codex 进程并提示重启 |

## 能力一览

### 账号管理

- **切换**：回车即切；已在使用中的账号自动拦截提示（不重写文件）
- **添加**：OAuth PKCE 登录（打开浏览器），自动去重入库；1455 端口被占自动回退 1457；超时可手动粘贴回调 URL
- **复活**：refresh_token 失效的账号原位重新登录，不产生重复条目
- **删除**：二次确认；使用中账号硬拦截

### 配额仪表盘

- 每账号显示速率窗口剩余百分比、**具体重置日期时间**（本地时区）
- 窗口类型按服务端下发时长自动分类（会话 5h / 周 / 月），不硬编码
- **重置卡**（rate-limit reset credits）数量与最早到期时间（只读展示）
- 查询前自动保证令牌新鲜，401 自动强刷重试一次

### 自检（doctor）

离线一键检查：账号库解析与备份、文件权限（600/700）、逐账号凭据完整性与过期时间、官方 auth.json 一致性、config.toml 冲突路由、残留锁。

### 双前端

- **TUI**（默认）：全屏仪表盘，左侧账号列表 + 右侧详情/配额 + 底部日志；`:` 命令面板（上下选择 / 输入过滤），所有动作收进面板防误触
- **经典菜单**：管道 / 非 TTY 环境 / `--classic` 参数时自动回退，编号交互

### 安全模型（明文 + 权限收紧）

- 凭据明文存储于 `~/.hangar/`，靠目录 `700` + 文件 `600` 收紧
- 原子写（唯一临时文件 + rename）+ `.bak` 备份自动回滚，崩溃不留半截文件
- 跨进程文件锁防双实例竞态（120s 过期自愈）
- 错误日志只记 `HTTP status + error_code + body_len`，**永不打印 token/body**
- 已知风险声明：明文存储；macOS keychain 同步经命令行传参（详见 `docs/design/scenarios.md` 安全声明）

## 安装与使用

### 构建

```bash
cargo build --release
# 产物：target/release/hangar（约 2.3MB，静态依赖无运行时要求）
```

### 运行

```bash
./target/release/hangar            # 默认 TUI（需要终端）
./target/release/hangar --classic  # 经典菜单（管道/非 TTY 自动回退）
```

### TUI 快捷键

| 键 | 作用 |
|----|------|
| `j/k` 或方向键 | 移动选中账号 |
| `/` | 输入过滤（按邮箱） |
| 回车 | 切换到选中账号 |
| `:` | 命令面板（添加/复活/删除/配额/自检/收敛），面板内 `/` 过滤、回车执行 |
| `q` | 退出 |

### 首次使用

1. 直接启动，按 `:` → 选「添加账号」→ 浏览器完成 ChatGPT 登录
2. 已有 Codex 登录账号？无需操作——启动时自动收编入库
3. 多账号重复步骤 1 即可；之后切换全是秒级

## 常见问题

**Q：切换后 Codex 没生效？**
Codex 进程内存中仍是旧凭据，重启 Codex 即可（工具会自动检测并提示）。

**Q：账号标了 ⚠ 需重新登录？**
该账号 refresh_token 已被服务端撤销。在 TUI 中选中它 → `:` → 「复活账号」，原位重新登录。

**Q：官方 auth.json 被我手动改坏了？**
harvest 对非法文件容错跳过，不会污染账号库；账号库自身损坏时从 `.bak` 自动回滚。

**Q：配额显示"未知"？**
wham/usage 为非公开接口，服务端字段可能变化。工具全容错解析，缺失字段显示未知，不影响其他功能。

本项目为个人效率工具，与 OpenAI 无官方关联；wham/usage 等接口为非公开契约，随时可能变化。
